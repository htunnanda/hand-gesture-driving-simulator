# Hand Gesture Driving Simulator

A driving simulator controlled by hand gestures.

## Project areas

- `hand-gesture/` — camera input, gesture detection, and calibration
- `control-logic/` — steering, acceleration, braking, and communication
- `unity-game/DrivingSimulator/` — Unity project
- `game-features/` — world design, traffic, and scoring
- `ui-ux/` — designs, assets, and HUD
- `integration-testing/` — integration tests and reports
- `docs/` — project documentation
