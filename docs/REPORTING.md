# Progress reports and collection

Each member submits a process report after every development session. Member 6 collects **all six** reports, checks missing submissions, and writes a consolidated team report.

## Individual report template
- Date / member / module
- Goal for the session
- Completed tasks and commit/PR links
- Tests and evidence
- Bugs, blockers and dependencies
- Next steps / expected completion date

## Member 6 checklist
- [ ] Check code changes from Members 1–5 and own integration work regularly
- [ ] Review every pull request and record findings
- [ ] Coordinate fixes and integration tests
- [ ] Collect reports from Members 1–6
- [ ] Compile one team progress report
- [ ] Track unresolved risks and responsible members
- [ ] Coordinate merges into `main`

Reports live in `integration-testing/reports/` or another team-approved system. Do not publish private recordings or identifying personal information.
